# Ptt-Alertor v2：開放朋友使用與懶人架設

日期：2026-10-10　接續 [精簡版設計](2026-10-10-slim-design.md)　對應版本：v1.0.0 起，各版變更見 [Releases](https://github.com/JA1221/ptt-alertor/releases)

## 目標

1. 開放朋友使用：管理員核准制，不再只限白名單
2. 優化 Telegram 互動與通知格式
3. 節省資源：小映像檔、少寫入、不用 `KEYS`
4. 懶人架設：雙擊啟動、網頁設定 token、點連結認領管理員、免編譯映像檔
5. 穩定性與 bug 修正

## 使用權限

Redis：`access:admins`、`access:members`、`access:pending`（set），`settings`（hash：`telegram_token`、`registration`、`claim_code`）。

- 管理員：`TELEGRAM_ADMIN_IDS`（相容舊的 `TELEGRAM_ALLOWED_IDS`），或在設定頁取得認領連結 `t.me/<bot>?start=<code>`
- 註冊模式（管理員用 `註冊 審核|開放|關閉` 切換，預設審核）
  - 審核：陌生人傳訊息 → 加入 pending，管理員收到「✅ 允許／❌ 拒絕」按鈕
  - 開放：直接成為成員；關閉：回覆不開放
- 管理員指令 `使用者`：成員與待審清單，可按鈕移除／核准
- 上限：每人 20 個看板、每看板 20 個關鍵字、50 篇推文追蹤
- 使用者封鎖 bot（403）→ 停用並移出關鍵字索引，不算 Telegram 異常；再次傳訊息自動恢復
- 舊資料遷移：`access:members` 不存在時，把現有啟用的使用者加入成員

## Telegram 互動

- 全部訊息用 HTML 格式，使用者內容一律跳脫
- 通知：同一使用者同一看板的新文章合併成一則，一篇文章只出現一次，標題為連結；下方一個「⚙️ 管理關鍵字」按鈕。推文通知附「🛑 停止追蹤推文」
- 通知上的按鈕只跳出提示（answerCallbackQuery），不覆蓋通知內容
- 選單操作，不用記指令：
  - 「➕ 新增」列出自己的看板與熱門看板 → 點看板 → 輸入關鍵字。等待輸入的狀態放在記憶體，10 分鐘失效，按其他按鈕或指令即取消
  - 「📋 清單」每個看板一顆按鈕 → 看板頁可刪單一關鍵字、刪整個看板（先確認）、在該看板新增
  - 「💬 推文清單」每篇附停止追蹤按鈕
  - 只傳一個詞 → 選看板直接加為關鍵字（英文詞也可選「這是看板」）
  - 看板頁「🧪 測試抓取」立即比對最新文章
- 常用鍵盤（新增、清單、推文清單、狀態、指令）與指令選單（setMyCommands）；bot 簡介空白時自動填入
- 輸入「stock 台積電」或貼上 ptt.cc／pttweb.cc 文章網址時，回覆一鍵新增按鈕
- 更新依使用者分組處理：同一人依序、不同人並行

## 網頁

- 只綁 127.0.0.1；所有 POST 檢查來源，下載備份也拒絕跨站請求
- 設定精靈：貼 token → 點認領連結
- 狀態頁：健康狀態、允許／拒絕申請、移除成員、切換註冊模式、幫成員新增刪除關鍵字、最近通知、備份下載與還原
- 頁面就地更新：每 30 秒在背景抓新內容替換，不重新載入、不跳回頂端；正在輸入時暫停。表單用 fetch 送出，結果以提示顯示
- 最近通知顯示 5 則，其餘收合

## 備份與版本

- 備份為可讀的 JSON（依 Redis 型別存 string／set／list／hash），還原在一個 MULTI 裡清空再寫入，格式錯誤時不動資料
- `backup.bat`／`backup.sh`：雙擊備份；拖曳備份檔還原，還原前先自動備份
- 推送 `v*` tag 發布 `x.y.z`、`x.y`、`x` 映像檔，`docker-compose.yml` 使用 `1`，更新不會跨大版本

## 資源與效能

- 映像檔 `FROM scratch`（內嵌時區資料），內建 `healthcheck` 子指令
- 看板沒有新文章時不寫入 Redis
- `KEYS` 改為 `SCAN`；關鍵字索引在指令後只更新該使用者，啟動時完整重建
- Redis 不對外開 port，設定記憶體上限

## 懶人架設

1. 安裝 Docker Desktop
2. 下載專案，雙擊 `start.bat`（macOS/Linux：`start.sh`）
3. 瀏覽器自動開啟設定頁：貼上 BotFather token → 點認領連結 → 完成

- GitHub Actions 建置 amd64/arm64 映像檔推到 GHCR；拉不到時自動本機編譯
- 再執行一次 start 即更新；第一次執行時詢問是否開機自動執行（HKCU Run「Ptt Alertor」）
- Windows 沒裝 Docker 時，`start.bat` 詢問後用 winget 安裝 Docker Desktop

## 穩定性

- 檢查看板是否存在的 HTTP 請求加上逾時
- 背景工作每輪 recover，panic 不會讓程式停止
- Redis 連線納入健康檢查與異常通知
- 設定頁 POST 檢查來源，避免跨站設定 token
